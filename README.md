# مُدَوِّن | Modawen Notes & Reminders

تطبيق ملاحظات وتذكيرات ذكية بنظام أندرويد عصري، مبني بالكامل باستخدام **Kotlin** و **Jetpack Compose** وفق أحدث معايير **Material Design 3**.

## المميزات الرئيسية
- **دعم كامل للغة العربية (RTL)** وتصميم أنيق يراعي اتجاه النصوص والواجهة.
- **إدارة الملاحظات والمهام**: إمكانية إنشاء ملاحظات نصية أو قوائم مهام تفاعلية (Checklist) مع شريط تقدير الإنجاز.
- **نظام التذكيرات الذكي**: تنبيهات دورية في الوقت الفعلي مع خيارات التأجيل (15 دقيقة) ومعاينة النغمات والتنبيهات.
- **ألوان وتصنيفات متعددة**: 7 لوحات لونية جذابة للملاحظات، وتصنيفات مرنة مع إمكانية إضافة تصنيفات مخصصة فوراً.
- **تثبيت وتفضيل الملاحظات**: الوصول السريع لأهم الملاحظات المثبتة والمفضلة.
- **البحث والفرز الفوري**: بحث سريع في العناوين والمحتوى والوسوم، وفرز حسب تاريخ التعديل أو الإنشاء أو الترتيب الأبجدي أو موعد التذكير.
- **النسخ السريع والمشاركة**: نسخ محتوى الملاحظات بضغطة زر وتنسيق مشاركتها بصيغة Markdown.
- **الأرشيف وسلة المهملات**: حماية الملاحظات من الحذف العرضي مع إمكانية الاستعادة أو الإفراغ النهائي.
- **مظهر نهاري وليلي (Dark / Light Mode)** وتبديل فوري لطريقة العرض (شبكي / قائمة).

## البنية التقنية (Architecture)
- **Kotlin & Jetpack Compose**: واجهات مستخدم معلنة كلياً بدون XML Layouts.
- **Material 3 (M3)**: ألوان متناسقة، خطوط مريحة للعين، وأيقونات دلالية غنية.
- **MVVM Architecture**: فصل تام بين طبقة البيانات (`NoteRepository`) وحالة التطبيق (`ModawenViewModel`) وواجهات المستخدم (`ModawenApp`).
- **Edge-to-Edge**: استغلال كامل لحواف الشاشة وشريط الحالة الشفاف.
